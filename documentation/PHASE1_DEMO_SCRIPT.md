# Phase One Demo Script

Release target: Aethina SMS Phase One - Client Acceptance and Pilot Release.

Use fictional demo data during the client walkthrough. Do not seed or reset hosted data without explicit approval.

## Demonstration Order

1. Administrator login and setup
   - Log in as Administrator.
   - Show dashboard, risk alerts, audit activity, users and roles.
   - Create or review the Head Teacher account.
   - Confirm self-deactivation is blocked.

2. Student and guardian management
   - Switch to DOS / academic administrator.
   - Register a fictional student with guardian details.
   - Show class, stream, academic year, and generated portal username.

3. Bursar invoice, payment, balance and receipt
   - Open Finance.
   - Show fee structure and invoice list.
   - Record a partial payment within the invoice balance.
   - Show updated balance and receipt row.
   - Use browser print for the receipt or fee statement.

4. Teacher assessment and marks entry
   - Log in as Teacher / Class teacher.
   - Select assigned assessment.
   - Enter marks, save draft, then submit for DOS review.

5. DOS review and publishing
   - Log in as DOS.
   - Approve and publish the assessment.
   - Generate or review report cards.
   - Use browser print for report output.

6. Timetable and teacher attendance
   - Show timetable entries.
   - Use teacher attendance kiosk flow.
   - Submit and approve an attendance correction.

7. Student / parent portal
   - Log in as the portal user.
   - Show home, finance, academics, report cards, timetable, announcements, and notifications.
   - Use browser print for portal fee statement or report card.

8. Approvals, auditability and offline synchronization
   - Show approval inbox.
   - Show audit log entries.
   - Show sync conflicts and protected tenant-scoped sync behavior.

9. Pilot limitations and next steps
   - Review known limitations.
   - Explain feedback and issue reporting.
   - Confirm the pilot support path and next review date.
